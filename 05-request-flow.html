Six security checkpoints — automatic.

While that request was flying, the architecture fired six security checks. You didn't write any of them by hand.

  • Auth verified — by tenantAction wrapper.
  • Feature flag checked — by requireFeature.
  • Permission checked — by requirePermission.
  • TenantContext type-checked at compile time.
  • RLS filter set in the transaction by tenantDb().
  • Postgres RLS policy double-checked the insert.

This is what "structural security" buys. The right thing happens because the architecture forces it — not because a developer remembered.
