Daily tools: generators & Claude Code.

Eight code generators, the TAP•IP plugin, and the superpowers skills. The tools that make you fast.

A. Code generators.

Generators emit scaffolding that follows TAP•IP's architectural rules. Instead of hand-writing 200 lines of boilerplate, you run one command. The generated code already follows §16 typed contexts, §18 error envelope, and §19 canonical helpers.

GeneratorEmits
generate:featureFull vertical slice (table + repo + action + page)
generate:drizzle-entityJust the data layer from a field spec
generate:repositoryStub tenant-scoped repository
generate:actiontenantAction CRUD for a repository
generate:operationAdds one operation to an existing entity
generate:constants§19 constants module + helpers + ESLint rule
generate:contextProvider + useX() hook
generate:componentErrorBanner-aware presentational component

Full guide: frontend/GENERATOR_GUIDE.md. Run any of them from inside frontend/ with npm run generate:<name> -- ...

B. The TAP•IP Claude Code plugin.

There's a custom Claude Code plugin at tap-ip-plugin/ with commands and skills tailored to TAP•IP work. You'll install it on day 1.

Commands

/babysit-pr <number>

Automatically pushes your PR through CodeRabbit review cycles until mergeable. Use this after you open your first PR.

/ship

The canonical "ship a feature" pipeline. Plans, implements, reviews, opens the PR.

/deliberate

Multi-agent deliberation for tough design decisions.

Skills (Claude Code activates these contextually)

  • tap-ip-work-a-ticket — how to work a ticket end-to-end.
  • tap-ip-discipline — engineering discipline rules.
  • canonical-helpers — the §19 canonical-helper pattern.
  • writing-codemod, running-deliberation, running-ship-pipeline — advanced. Recognize the names; you'll grow into them.

C. Superpowers skills.

Anthropic ships a separate plugin of general-purpose skills. The ones you'll use most:

superpowers:brainstorming

Explores user intent + requirements before building. Use it for your own product ideation in the stretch goal.

superpowers:writing-plans

Turns a vague task into a structured implementation plan.

superpowers:verification-before-completion

Forces "show evidence" before claiming work done.

superpowers:requesting-code-review

Dispatches a reviewer subagent for your work.

superpowers:test-driven-development

Write the test first, then the code.

For your first 2 weeks, you only need brainstorming and writing-plans. Everything else is for later.
